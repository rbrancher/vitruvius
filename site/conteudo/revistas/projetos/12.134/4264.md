<p class="text">El complejo acu&aacute;tico deber&iacute;a satisfacer las necesidades de las futuras competencias y al mismo tiempo servir como nuevo centro de formaci&oacute;n en nataci&oacute;n.</p>
<p class="text">Requer&iacute;a cuatro nuevas piscinas (una ol&iacute;mpica de 50m x 25m, otra de 30m x 25m para nado sincronizado y dos de 50m x 25m para ense&ntilde;anza).</p>
<p class="text">La propuesta consisti&oacute; en articular estas cuatro piscinas mediante un sistema de jardines con vegetaci&oacute;n t&iacute;pica en los bordes de humedales tropicales. Un paisaje acu&aacute;tico que funciona como sistema para separar las zonas p&uacute;blicas de las &aacute;reas para deportistas.</p>
<p class="text">La arquitectura esta siempre en constante tensi&oacute;n y dependencia con los jardines.</p>
<p class="text">El programa requer&iacute;a un sistema complejo de ba&ntilde;os y camerinos para nadadores y p&uacute;blico general, estas &aacute;reas se encuentran bajo el nivel de las piscinas y las cubiertas son plantadas con jardines. Un sistema de patios bajo el nivel de la tierra ilumina naturalmente estas zonas y funciona como lugar de reuni&oacute;n y calentamiento para los deportistas.</p>
<p class="text">El &uacute;nico edificio que sobrepasa el nivel de las piscinas es una pieza alargada y permeable para las &aacute;reas administrativas. Este edificio funciona al mismo tiempo como palco para la piscina de nado sincronizado, terraza p&uacute;blica e ingreso principal.</p>
